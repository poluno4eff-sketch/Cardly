# Техническое задание — Cardly 0.1

## Цель этапа

Получить первую самостоятельную рабочую версию Cardly для Android + Wear OS, которая устанавливается, показывает карты и создаёт основу для дальнейшего добавления реальных данных и синхронизации.

## Телефон

1. Главный экран в утверждённом стиле Cardly.
2. Три крупные карты одновременно в видимой области на типичном современном смартфоне.
3. Верхняя панель: Cardly, поиск, настройки отображения, сортировка, меню.
4. Кнопка `+` справа внизу.
5. AMOLED-чёрный фон.
6. Карточки одинакового размера и со скруглёнными углами.
7. Следующий подэтап: форма добавления карты и реальная модель данных.

## Wear OS

1. Экран «Мои карты».
2. Крупные строки/миниатюры карт.
3. Тап по карте открывает экран кода.
4. Экран кода должен быть максимально контрастным.
5. Следующий подэтап: генерация настоящего штрихкода и автоматическая максимальная яркость.

## Синхронизация — следующий подэтап

1. Собственная локальная база на телефоне и часах.
2. Передача метаданных через Wear OS Data Layer `DataClient`.
3. Передача изображений через `Asset`.
4. `MessageClient` использовать только для команд/ручного запроса синхронизации.
5. Карты должны оставаться доступными на часах при отключённом телефоне.

## Добавление карт — план

- ручной ввод;
- сканирование камерой;
- распознавание кода с изображения;
- фото лицевой и обратной стороны;
- выбор цвета/шаблона;
- название, номер, заметка, срок действия;
- избранное и группа.

## Поддерживаемые коды — план

Code 128, Code 39, Code 93, Codabar, EAN-13, EAN-8, ITF, UPC-A, UPC-E, QR, PDF417, Aztec, Data Matrix.

## Импорт/экспорт — после ядра

- локальная резервная копия;
- импорт/экспорт файла Cardly;
- импорт изображений;
- позже рассмотреть совместимый импорт распространённых открытых форматов без копирования чужого кода.

## Ограничения

- не копировать исходный код Catima;
- не копировать исходный код Skidko;
- не использовать их ресурсы/иконки;
- не добавлять обязательный аккаунт;
- не добавлять рекламу и аналитику без отдельного решения;
- не перегружать главный экран.
