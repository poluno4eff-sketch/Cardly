# Cardly by Alex

Cardly by Alex — независимое Android-приложение для хранения дисконтных, клубных и других карт с приложением-компаньоном для Samsung Watch / Wear OS.

Cardly by Alex (poluno4eff). Открытый исходный код, лицензия GNU GPL v3 — см. `LICENSE` и `NOTICE.md`.

## Принципы проекта

- Открытый исходный код (GPL-3.0).
- Catima — референс функций и UX.
- Экран оплаты на часах основан на Mir Pay Wallet (the-dise, GPL-3.0).
- Телефон и часы имеют собственное локальное хранилище карт.
- Синхронизация телефон ↔ Wear OS проектируется через официальный Wear OS Data Layer.
- Приложение должно полноценно работать без обязательного аккаунта и без Интернета.
- Главный экран: крупные карты, минимум лишних элементов, утверждённый дизайн Cardly.

## Текущий этап

Версия 0.3.0 — новый интерфейс телефона, визитки с распознаванием, две стороны карты, ярлыки карт на иконке.

## Модули

- `mobile` — приложение для телефона/планшета.
- `wear` — приложение для Wear OS.
- `core:model` — модели предметной области.
- `core:data` — локальное хранилище и репозитории.
- `core:sync` — синхронизация между телефоном и часами.
- `core:barcode` — распознавание и генерация штрихкодов.

## Сторонние компоненты

- Tesseract / Tesseract4Android, Leptonica — Apache 2.0 (распознавание текста визиток), модели `tessdata_fast` rus/eng — Apache 2.0.
